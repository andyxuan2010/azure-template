# Basic Intune App Deployment Example

Demonstrates the input shape. The sample payload is illustrative; replace it with a complete configuration supported by the selected Microsoft Graph endpoint. Do not apply placeholder Autopilot hardware identities or app metadata.


Initialize and validate this example with:

```shell
terraform init -backend=false
terraform validate
```

This example creates or changes tenant configuration and has no Azure infrastructure cost by itself. Microsoft 365 licensing and any services affected by these settings may incur charges; check your tenant licensing and service plans.
