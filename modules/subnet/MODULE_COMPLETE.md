# Subnet Module Complete

The subnet module includes:

- Terraform implementation for Azure subnets in an existing virtual network.
- Optional NSG and route table associations.
- Optional subnet delegations, service endpoints, service endpoint policies, and private endpoint policy controls.
- Optional virtual-network scoped app admin and app user RBAC assignments.
- Provider-mocked Terraform tests.
- README, examples, quick reference, and module index documentation.
